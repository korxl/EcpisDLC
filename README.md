# EcpisDLC

Клиентский Fabric-мод для Minecraft Java 1.21.11. Click GUI открывается на Right Shift. Нативный планшет и HUD создаются отдельными Java AWT/Swing окнами ОС, без отрисовки Minecraft GUI/HUD.

## Без Minecraft-рендера для GUI/HUD

Планшет и HUD рисуются Java AWT/Swing в прозрачных окнах операционной системы. Для блокировки игрового ввода GUI открывает пустой Minecraft Screen, который ничего не рисует; сам интерфейс и HUD не используют Minecraft GUI/HUD renderer. Мировую сцену продолжает отрисовывать Minecraft как обычно.

Используйте оконный или безрамочный режим. В эксклюзивном полноэкранном режиме, на Wayland и в некоторых оконных менеджерах внешние окна-оверлеи могут не отображаться поверх игры или не совпадать с её позицией.

## Функции

- **Fullbright** — включает максимальное стандартное значение гаммы Minecraft и восстанавливает исходное значение при выключении. Это не X-ray.
- **AutoTotem** — если рука пуста или в ней другой предмет, меняет тотем из инвентаря в левую руку через обычный inventory swap. Не работает, пока открыт контейнер/экран инвентаря.
- **AutoTool** — при удержании атаки автоматически выбирает на панели быстрого доступа инструмент с наибольшей скоростью добычи целевого блока, а после отпускания атаки возвращает прежний слот. Ручное переключение слота во время атаки не перезаписывается.
- **HUD** — отдельные AWT-элементы TargetHUD (показывается 3,5 секунды после атаки с 300 мс затуханием), PotionHUD, ModuleListHUD, ArmorHUD и Notifications. Каждым элементом можно управлять из настроек HUD в категории Render.
- **Редактор HUD** — кнопка Edit HUD в настройках HUD или открытый игровой чат показывает отключённые элементы, позволяет перетаскивать их и привязывает к соседним элементам с допуском 8 пикселей. Позиции и переключатели элементов сохраняются в `config/ecpisdlc/hud.json`.
- **Coordinates** — показывает/скрывает координаты в отдельном HUD-элементе.
- **Click GUI** — категории Combat, Movement, Render, Player, Configs и Binds; поиск, карточки, панель параметров, профили и переназначение клавиш.
- **Ambience** — локальные пресеты времени суток и погоды, цвет/дальность тумана, цвет и видимость облаков, а также локальную регулировку гаммы. Все изменения только клиентские: игровое время и состояние мира не меняются, пакеты не отправляются.
- **Светлая и тёмная темы** — выбираются в блоке Appearance; обе палитры сохраняются между запусками. Переходы между разделами, открытие планшета и переключение модулей используют плавные анимации.

Рабочие игровые функции: Fullbright, AutoTotem, AutoTool, Ambience, HUD-элементы и Coordinates. Delay и Health у AutoTotem применяются в игре; AutoTool использует инструменты только из панели быстрого доступа; Ambience управляет только визуальным временем, клиентским чтением осадков, параметрами рендера тумана/облаков и гаммой. Клавиши по умолчанию — G, T, N, H, C и M; их можно переназначить в Binds. Остальные модули и параметры остаются UI-заготовками и помечены UI ONLY. Размер окна, категория, тема, значения настроек, бинды и профили сохраняются в `config/ecpisdlc/ui.json`; HUD-позиции и переключатели — в `config/ecpisdlc/hud.json`.

## Ambience: точки вмешательства Yarn 1.21.11

- `SkyRendering#updateRenderState(ClientWorld, float, Camera, SkyRenderState): void` — меняются только `sunAngle`, `moonAngle`, `starAngle` и `rainGradient` в состоянии кадра; `World#getTimeOfDay()` не переопределяется.
- `World#getRainGradient(float): float` и `World#getThunderGradient(float): float` — локальная подмена значений только для `ClientLevel`, без вызова setter-ов и без сетевых пакетов.
- `FogRenderer#applyFog(Camera, int, RenderTickCounter, float, ClientWorld): Vector4f` и внутренний писатель `FogRenderer#applyFog(ByteBuffer, int, Vector4f, float, float, float, float, float, float): void` — цвет и дальность только в fog buffer рендера.
- `CloudRenderer#renderClouds(int, CloudRenderMode, float, Vec3d, long, float): void` — локальное скрытие/тонирование облаков.

Код проекта собирается с Mojang mappings; mixin-селекторы указывают соответствующие intermediary-имена Minecraft 1.21.11. Пустой `OverlayInputScreen` только блокирует ввод игры: GUI и HUD остаются Java AWT/Swing окнами ОС.

## UI Preview

`index.html` — интерактивный макет интерфейса с карточками, настройками Ambience и HUD, конфигами, биндами, двумя темами и нарисованными SVG-иконками. Макет не запускает Minecraft и не подключается к моду. Нажмите Run в FreeMilk, чтобы открыть превью.

## Установка

Нужны Java 21, Fabric Loader 0.20.1+ и Fabric API для Minecraft 1.21.11. Скопируйте `EcpisDLC-1.0.0.jar` в папку `.minecraft/mods` вместе с Fabric API.

Чтобы скачать собранный JAR из GitHub, откройте **Actions → Build EcpisDLC → последний успешный запуск → Artifacts → EcpisDLC-jar**. Workflow собирает JAR и публикует его как artifact каждого запуска на 90 дней.

## Сборка

Из корня проекта с установленным Gradle 9.8.2 и JDK 25 (актуальный Loom требует JDK 25 для сборки; сам JAR компилируется с `--release 21` и запускается на Java 21):

```text
gradle build
```

Готовый remapped JAR появится в `build/libs/`.
