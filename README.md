# EcpisDLC

Клиентский Fabric-мод для Minecraft Java 1.21.11. Первый прототип включает планшетное Click GUI размером 620×440 (открывается на Right Shift), Fullbright, AutoTotem и отдельный HUD.

## Без Minecraft-рендера для GUI/HUD

Планшет и HUD рисуются Java AWT/Swing в прозрачных окнах операционной системы. Для блокировки игрового ввода GUI открывает пустой Minecraft Screen, который ничего не рисует; сам интерфейс и HUD не используют Minecraft GUI/HUD renderer. Мировую сцену продолжает отрисовывать Minecraft как обычно.

Используйте оконный или безрамочный режим. В эксклюзивном полноэкранном режиме, на Wayland и в некоторых оконных менеджерах внешние окна-оверлеи могут не отображаться поверх игры или не совпадать с её позицией.

## Функции

- **Fullbright** — включает максимальное стандартное значение гаммы Minecraft и восстанавливает исходное значение при выключении. Это не X-ray.
- **AutoTotem** — если рука пуста или в ней другой предмет, меняет тотем из инвентаря в левую руку через обычный inventory swap. Не работает, пока открыт контейнер/экран инвентаря.
- **HUD** — отдельная панель с именем игрока, здоровьем, количеством тотемов и координатами.
- **Coordinates** — показывает/скрывает координаты на HUD.

## Установка

Нужны Java 21, Fabric Loader 0.20.1+ и Fabric API для Minecraft 1.21.11. Скопируйте `EcpisDLC-1.0.0.jar` в папку `.minecraft/mods` вместе с Fabric API.

Чтобы скачать собранный JAR из GitHub, откройте **Actions → Build EcpisDLC → последний успешный запуск → Artifacts → EcpisDLC-jar**. Workflow собирает JAR и публикует его как artifact каждого запуска на 90 дней.

## Сборка

Из корня проекта с установленным Gradle 9.8.2 и JDK 25 (актуальный Loom требует JDK 25 для сборки; сам JAR компилируется с `--release 21` и запускается на Java 21):

```text
gradle build
```

Готовый remapped JAR появится в `build/libs/`.
